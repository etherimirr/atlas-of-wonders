# 奇境旅图 · Atlas of Wonders

一张魔幻风格的个人旅行地图 —— 世界缩放到美国，走过的地方点亮成金色星光，没去过的化作待解锁的谜题符文。

**在线预览**：https://etherimirr.github.io/atlas-of-wonders/

## ✨ 三个部分

- **地图** — 星空世界地图，去过的城市是金色星章，心愿点是待点亮的六边形符文；点开任意一站看攻略、出片机位、全年 12 个月适合度。
- **游记** — 每一趟旅程一篇过去式手记，由照片的时间与位置自动重建逐日行程，并各用一位作家的笔法写成（马尔克斯 / 海明威 / 三毛 / 张爱玲 / 汪曾祺 / 李碧华 / 史铁生 / 余华 / 当年明月 / 莫言 / 席慕容 / 琼瑶 / 老舍）。
- **规划** — 面面俱到的行程规划台：交通、住宿、门票、逐日安排、出片攻略、穿搭、省钱与幸福度 tips、预算，每项都带一键「查最新价」。按签证难易与实际情况排序。

## 🗺️ 特性

- 缩放分级地名（大洲 → 国家 → 城市 → 具体景点），像真地图
- 每个心愿点带**全年 12 个月适合度热力条**，一眼看出几月去最好
- 手机端自适应：单指拖动、双指缩放
- 完全**自包含**的单个 `index.html`，无任何外部依赖，离线也能开

## 🚀 怎么看

直接用浏览器打开 `index.html` 即可（手机、电脑都行）。无需安装、无需联网。
